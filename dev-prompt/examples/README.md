# Examples

Fictional, generic examples of generated output. They show size and tone, not required content.

- `small-project/`: a personal command-line tool. Three files in total: one combined spec, one agent instruction file, one implementation prompt. No roadmap, no architecture file.
- `comprehensive-project/`: a multi-platform app. Shows the file set, a roadmap, a milestone prompt, and the agent instruction file. Excerpts only.

Both assume the user chose: single agent, no subagents, Git on a single branch with local commits, no push.
